[center][b]
WHAT DOES THIS MOD DO?
- An Omega core can govern your colony, with three administrator skills of its own.
- Only an Omega core can take a colony past size 10, up to size 15.


Colonies past size 10 become Arcology Worlds, then Ecumenopolises, then Hyper-Ecumenopolises: the planet turns into a city, lit day and night, with an orbital ring at size 15.
Take the Omega core away from one and it falls into a Great Civil War.
A continuation of Planetace's Astral Ascension, made with the original author's blessing.


The code is fully open source. You don't have to credit me. Claude Code built this anyway.

[hr][center][size=12pt][b]The Omega Core Administrator[/b][/size][/center][hr]
[list]
[li]Assign an Omega core as administrator the same way as an Alpha core.[/li]
[li][b]Ethereal Enlightenment:[/b] hazard rating -25%, ship quality +25%, every building's production x2 and demand halved, +1 maximum industries.[/li]
[li][b]Acumenious Oracle:[/b] stability +3, ground defenses x3, fleet size x2.[/li]
[li][b]Delphic Optimiser:[/b] colony income x1.25, colony upkeep x0.75, accessibility +50%.[/li]
[/list]
[hr][center][size=12pt][b]Colonies Past Size 10[/b][/size][/center][hr]
[list]
[li]Colonies grow to size 10 on their own (the base game stops at 6; this is a setting). Past 10, only a colony governed by an Omega core keeps growing, up to 15.[/li]
[li]Every size past 10 takes 1.5 times longer to reach than it normally would, and it compounds. Size 15 is a lifetime's work.[/li]
[/list]

[hr][center][size=12pt][b]The Great Civil War[/b][/size][/center][hr]
[list]
[li]A colony past size 10 is too big to be governed by a lesser mind.[/li]
[li]Try to remove its Omega core and you get a warning, the way the base game warns about a rogue Alpha core.[/li]
[li]Go through with it and the colony drops to size 8, keeps an armed, ungoverned population in its ruins, and loses 5 stability for half a year. You get the core back.[/li]
[/list]
[hr][center][size=12pt][b]AoTD Compatibility[/b][/size][/center][hr]
[list]
[li]AoTD - Theory of Toolbox doubles food demand, domestic goods demand and farm output with every colony size. Past size 10 that doubling is held at its size-10 amount, so one size 15 world cannot outweigh the rest of the Sector.[/li]
[li]Below size 11 nothing changes. It can be switched off in the settings.[/li]
[/list]
[hr][center][size=12pt][b]Settings[/b][/size][/center][hr]
[list]
[li]In LunaLib's settings menu ([b]Shift+F2[/b] in the campaign): the size limit without an Omega core (6 to 10), how much slower growth past 10 is, the AoTD cap, and Omega core drops.[/li]
[/list]

[spoiler=Console commands]
With Console Commands installed. Leave out the colony name to use the colony you are docked at.
[b]aar_size <3-15> [colony][/b] - set a colony's size past the usual 10, with its stage and planet look. Past 10 the colony needs an Omega core administrator first.
[b]aar_growth <0-100> [colony][/b] - set how far a colony has grown towards its next size.
[b]aar_status [colony][/b] - size, size limit, growth, administrator, stage and AoTD scaling.
[/spoiler]
[spoiler=FAQ]
[b]Where do I get Omega cores?[/b]
Destroyed Omega ships can drop the core that commanded them: 33% for a frigate, 66% for a destroyer, 99% for a cruiser, always for a capital. If Omega Core Everywhere is installed, its drop settings are used instead.
[b]Can I run it with the original Astral Ascension?[/b]
No. This mod replaces it, and the game will not start with both enabled.
[b]Can I continue a save from the original Astral Ascension?[/b]
No. Start a new game, or use a save that never had the original.
[b]Can I add it to an existing save?[/b]
Yes.
[b]Can I remove it from a save?[/b]
Not once a colony has an Omega core administrator or has grown past size 10.
[b]What about big worlds from other mods?[/b]
They are left alone, unless you give one an Omega core administrator.
